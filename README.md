# Rules of Crust

1. Every function is unsafe.
2. No references, only pointers.
3. No cargo, build with rustc directly.
4. No std, but libc is allowed.
5. Only Edition 2021.
6. All user structs #[derive(Clone, Copy)].
7. Everything is pub by default.

_The list of rules may change. The goal is to make programming in Rust fun._
